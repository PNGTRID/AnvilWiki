## 先看一个真实场景

做菜前先把锅碗摆上台面——这一课就是摆锅碗。后面每一课都要用的 6 样工具,在这里一次装齐;**跳过任何一样,下一课的第一条命令就会卡住**。好消息:只装这一次,以后永远不用再装。

## 本课做完你会拿到

- 6 样全部就位、逐样验证过的工具
- 一个开着两步验证、丢了也能找回的 GitHub 账号——**它是你全部生产资料的保险柜**(站点、内容、将来的广告费都挂在上面)

### 装备 1:终端(打字指挥电脑的窗口)

- **Mac**:按 `Command + 空格`,输入「终端」(Terminal),回车打开。
- **Windows**:开始菜单输入「PowerShell」,回车打开。

**你会看到**:一个闪烁的光标,前面有电脑名和 `~` 或 `>`。以后手册说「在终端输入」,就是在这里打字按回车。

### 装备 2:GitHub 账号 + 两步验证(你的保险柜)

打开 [github.com](https://github.com),点右上角 Sign up,用邮箱注册免费账号。用户名起个正经的——它会出现在你的网站地址里。

注册完**立刻做两件事(30 秒)**:进 Settings → Password and authentication 开启 **Two-factor authentication(两步验证)**;把生成的**恢复码(recovery codes)存进密码管理器或写在本子上**。为什么这么急:GitHub 账号一旦被盗,你的站、你的文章、你将来的广告收入全部易主;而开了两步验证的账号,小偷偷到密码也进不来。恢复码是手机丢了时唯一的门——锁在只有你知道的地方。

**你会看到**:能登录,右上角有你的头像,两步验证显示已开启。

### 装备 3:Node(网站引擎的底座)

Node 是让这套模板跑起来的底座软件,版本需要 **22.13 或更新**。

- 打开 [nodejs.org](https://nodejs.org),下载左边 LTS 版本,双击安装,一路下一步。
- 装完**新开一个终端**(旧的要关掉重开),输入 `node -v` 回车。

**你会看到**:类似 `v22.14.0` 的一行字,开头是 22 或更大。

### 装备 4:pnpm(搬运工,一条命令装齐网站零件)

终端输入:

```bash
npm install -g pnpm
```

**你会看到**:几行进度,最后没有红色 error。输入 `pnpm -v` 回车,显示版本号即成功。

### 装备 5:Git(把文件送进仓库的搬运车)

- **Mac**:终端输入 `git -v` 先试试,很多 Mac 自带;没有就 `brew install git`(没装 brew 先到 [brew.sh](https://brew.sh) 按首页命令装)。
- **Windows**:到 [git-scm.com](https://git-scm.com) 下载安装,一路下一步。

**你会看到**:`git -v` 显示版本号。

### 装备 6:AI 编程助手(写内容的搭档)

从 ZCode / [Claude Code](https://claude.com/claude-code) / [Codex](https://openai.com/codex) / [Cursor](https://cursor.com) 里**任选一个**装上(都有免费额度)。本课还用不到它,产页那一课它就是主角。

**你会看到**:软件能打开,你知道怎么新建一个对话。

## 三个经典错误(提前替你踩)

- **`pnpm` / `node` 提示 command not found**:十有八九是装完没**重开终端**——旧终端不认识新装的工具。关掉重开再试。
- **Node 官网打不开、下载慢**:换网络环境,或用手机热点下载安装包再传到电脑。装不上 Node,后面全部停摆,值得多花十分钟。
- **Mac 装 brew 报错**:先确认 `git -v` 是不是本来就能用(很多 Mac 自带,那就跳过 brew);实在要装,照 [brew.sh](https://brew.sh) 首页那行命令**逐字**复制。

## 本课新词(就 3 个)

- **终端**:用打字方式向电脑下命令的窗口,后面每课的操作都在这里。
- **仓库(repository)**:GitHub 上存放一整套网站文件的地方,你的「店面仓库」。
- **LTS**:Long-Term Support,长期支持版——最稳、官方维护最久的版本,永远选它。

## ✅ 验收(全部成立才算完成)

- ☐ 终端能打开,你知道在哪里打字
- ☐ `node -v` 显示 22 以上,`pnpm -v` 和 `git -v` 都有版本号
- ☐ GitHub 能登录,**两步验证已开,恢复码已存**
- ☐ AI 助手装好,能新建对话
