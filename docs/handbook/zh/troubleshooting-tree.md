## 用法

对着症状找行,按顺序做,第一条不解决再做第二条。每行末尾指回对应课。

## 没收录(或收录极慢)

1. GSC 里确认 sitemap 已提交、重点页点过「请求收录」→ 课 19
2. `pnpm check-sitemap` 看产物里的地址是否都 200
3. 内容 <10 篇?先补到首版量级再等——空站收录本来就慢
4. SITE_URL 是正式域名吗?wrong 域名=提交了一个不存在的站(课 18)

## 页面 404

1. 地址末尾有 `/` 吗?全站强制尾斜杠(缺斜杠会 404)
2. 分类目录、navigation.ts、语言 JSON 三处一致吗?`pnpm check-config` 定位
3. 那篇是不是 `draft: true`?草稿只在本地开发模式可见
4. 改过路由文件后 build 过吗?路由错误只在构建时暴露(课 16)

## 构建红了

1. 看**最后一行**报错——90% 的答案在那里
2. 报错提到 frontmatter → 登记卡格式问题,对照报错字段修
3. 报错提到分类 → `pnpm check-config`
4. 看不懂就整段贴给 AI:「这个报错怎么修」(课 16)

## 广告位空白

1. 四个变量名拼写完全一致吗(区分大小写)?→ 课 22
2. 填完重新部署了吗?
3. 新站新广告位填充要几小时到几天——先等等
4. 一直空白且广告已过审:AdSense 后台看站点状态是否「已就绪」

## 统计没数据

1. GA4:访客(包括你自己)点过同意横幅吗?没点不加载,这是设计(课 24)
2. 填完 token/ID 重新部署了吗?→ 课 20
3. GA4 常规报表延迟 24-48 小时——实时报告才是即时验证通道
4. Clarity 状态一直 pending:确认脚本只贴了一次、贴在 `</head>` 前(课 20)

## 排名不涨

1. 先看词的竞争度:第一页是专业站还是论坛帖?专业站盘踞就退到长尾词(课 28)
2. 单页自检清单跑过吗?title/直答 summary/表格/封面逐项查(课 28)
3. 内容过期了吗?`pnpm refresh-audit`,P0 清零(课 25)
4. 4-12 周的波动是常态——只看长期趋势(课 29)
