## 先看一个真实场景

搜「best characters」的玩家不想读三千字,他想要一张表:**谁强、为什么、我现在该练谁**。排行榜页就是把你的游戏理解做成一张表——AI 负责格式,判断必须是你给的。同一场戏的另一半:纯文字页在游戏 wiki 里没有竞争力,图片和视频才是「我真玩过」的证据。

### 第 1 步:排行榜页提示词(整段复制)

```text
用我的评价写一篇 tier list 页。
【素材】<角色/装备清单 + 我的排名理由>
要求:表格为主,每行一句结论性理由;争议排名用 Callout warn 注明版本敏感;
frontmatter 加 gameVersion;未实测对象标 [待补充] 或整篇 draft: true,不许编造。
写完运行 pnpm check-content && pnpm build,全绿才算完成。
```

`gameVersion` 这行别删:排行榜天生随版本过期,登记了版本号,过时了才知道该更新哪篇。

### 第 2 步:配图与视频,三条合法通道

| 通道 | 拿什么 | 怎么用 |
|---|---|---|
| **自己截/自己录** ✅ 首选 | Boss 特写、装备面板、地图;你录的打法视频 | 截图拖进对话;视频传 YouTube 后给链接 |
| **官方素材** ✅ | 游戏官网 press kit、官方发布的截图宣传图 | 按官方条款用,注明出处 |
| **CC 图库** ✅ | 带知识共享授权的通用配图 | 仅用于非游戏画面(横幅/装饰) |

**AI 不能替你生成「游戏截图」**,网上随手扒图是版权风险——这两条路都堵死,唯一坦途是自己产。暂时没素材就先跳过这步,纯文字先上线,图后补。素材密度参考 `docs/content-format.md` 的「媒体密度建议」表。

```text
给 <文章路径> 这篇配图。
【素材】
截图:<拖进对话,或写明文件路径>
视频:<YouTube 链接>(没有就删掉这行)
【要求】
按 docs/content-format.md 媒体密度建议放置:正文插图用 ![alt](/images/articles/...),
alt 写清楚图里是什么;机制/路线图进 frontmatter gallery,每张配 caption + alt;
视频登记进 frontmatter videos 并内联到对应小节。不要描述图里没有的内容。
写完运行 pnpm check-content && pnpm build,全绿才算完成。
```

## 三个经典错误(提前替你踩)

- **没玩过的角色也排个名**:要么实测,要么标 `[待补充]`,要么整篇 draft——「看起来完整」的排行榜比空着更害人。
- **网上扒图**:版权投诉一封,页面下架、站扣分。三条合法通道之外的图,一律不用。
- **alt 空写或乱写**:alt 是图片的文字替身(读屏和 Google 都靠它),写清楚图里是什么,别写「配图1」。

## 本课新词(就 3 个)

- **tier list(强度榜)**:按强度分档的排行表,你的游戏理解产品化。
- **gameVersion**:登记「这篇基于哪个版本写的」,版本一换你就知道哪些页要重看。
- **alt text**:图片的文字说明,给读屏器和搜索引擎看——也是你图片 SEO 的一半。

## ✅ 验收(全部成立才算完成)

- ☐ 排行榜页通过质检,每行有一句结论理由,登记了 gameVersion
- ☐ 至少一篇页面配上了合法来源的图或视频
- ☐ 所有图片的 alt 都写清楚了图里是什么
