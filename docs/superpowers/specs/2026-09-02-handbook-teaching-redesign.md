# 手册教学法重构：学习手册 29 课 + 开发手册 9 课（定案）

日期：2026-09-02 · 状态：✅ 全部完成——五批随 v2.8.0~v2.12.0 发版（学习手册 29 课+3 附录、开发手册 9 课）

## 背景与裁决

用户裁定现行手册三宗罪：找词（最重要的技能）在手册里只有半章且关键方法甩给 GitHub 上的
docs/sourcing.md；每章 1/3 篇幅是固定仪式（废话）；关键词主线散落 4 章无地图（节奏乱）。
重构原则：一课一事、例子先于概念、每课新词 ≤3 且放文末、产出即验收、错误前置、主线地图。
单课 800-1200 字（现约 2200），总量持平略降。已核实 parity 测试不钉章数，门禁无阻碍。

## 已定决策

1. **命名用「课」**；标题不再硬编码「第 N 章」——编号由 frontmatter `manual` + `order` + 阶段呈现。
2. **slug**：旧章一对一映射的 10 个原样保留（install-tools / theme-and-homepage / put-site-online /
   get-on-google / enable-ads / weekly-ops / batch-pages / architecture / categories-and-locales /
   integrations）；被拆旧章映射到最对应新课：pick-your-game→find-candidates、launch-your-site→
   run-your-site、first-10-pages→first-article、templatize-your-site→clone-your-site、
   seo-traffic→rank-one-keyword、sync-and-contribute→sync-upstream、ci-and-security→verify-your-changes、
   ai-ops→ai-ops（保留）。
3. **执行分批**：第一批 = 阶段 0+1（8 课，找词线先行）；之后每阶段一批；每批走全门禁 + 发版。
4. 同步点：「学习手册 11 章/开发 7 章」字样在 docs/README.md、landing.ts 文案、AGENTS.md 等处，
   随第一批一并清零；tldr ≤480 schema 上限照守。

## 每课统一骨架

真实场景开场 → 本课产出（一句话）→ 编号步骤（每步带「你会看到什么」）→ 三个经典错误（前置）→
词卡（≤3，文末）→ 产出验收（可交付物）→ 下一课钩子。比喻每课最多一个。

## 明确不加

newsletter/推送（模板无功能）；社媒运营大全、黑帽外链（超范围/害人）；更多变现深水区（没流量学了只焦虑）。
