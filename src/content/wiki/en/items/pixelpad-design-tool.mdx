## What is PixelPad?

PixelPad is a browser-based graphic design tool in the Canva/Figma neighborhood: templates for social posts and decks, a layer-based editor, team libraries, and one-click exports. The pitch is zero install — files live in the cloud, the editor runs in a tab, and sharing is a link. Three product surfaces matter in practice:

1. **The editor** — layer-based canvas with the standard toolset (text, shapes, images, masks) and a template library for the usual formats.
2. **Brand kits** — on Pro, stored fonts, palettes, and logos that snap into any template. The feature that decides most upgrades.
3. **Team spaces** — on Team, shared libraries, comment threads, and per-seat permissions.

## Who PixelPad is for — and when to pick something else

**A good fit when:** you produce social graphics, slide decks, or simple print pieces regularly; you want zero install; or a small team needs shared templates more than it needs a full vector toolchain.

**Look elsewhere when:** you need pixel-precise vector editing, offline work, or versioned design files — a desktop vector suite fits better. And if your actual job is notes rather than design, the other tool on this site is the better spend: the [CloudNote notes app](/items/cloudnote-notes-app/) card covers a notes-first subscription at a lower price point, with its own [coupon page](/codes/cloudnote-codes/).

## About the suggestion slot at the end of this page

Pages like this one end with an optional **affiliate suggestion card** — the monetization slot for tool-entity content. On this template it is config-gated and ships empty, so nothing renders until a site owner adds picks. The wiring, for anyone reusing this page format:

```ts
// src/config/affiliates.ts — empty array = the slot renders nothing
export const affiliates = {
  suggestions: [
    {
      url: 'https://www.pixelpad.example/',
      title: 'Try PixelPad Pro',
      description: 'The design tool covered on this page.',
      categories: ['items'],
    },
  ],
};
```

Three things the slot handles automatically: the link gets `rel="sponsored nofollow noopener"`, a localized sponsored-disclosure label, and a max of two cards per page. Never hardcode affiliate links into article bodies — the config file is the single place to swap picks, and empty stays render-nothing (the same out-of-box contract as ads and comments).
