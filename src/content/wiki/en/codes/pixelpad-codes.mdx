## How do I redeem a PixelPad coupon code?

Redeeming takes under a minute once you know where the box hides:

1. Sign in and open **Settings → Billing** — the same panel you use to switch plans.
2. Select the plan the code targets (Pro for DEMO-BLACK50 and DEMO-PAD20, Team for DEMO-TEAM15), then click **Add promo code**.
3. Paste the code exactly as written above and press **Apply**. Codes are case-sensitive and the dash in every entry is a plain hyphen.
4. Check the recalculated total, then confirm payment. If the price did not change, the code was rejected — see the troubleshooting notes below.

**If a code from the active list is rejected:**

- **"Code expired or invalid"**: it most likely lapsed after our last re-test. Leave a comment on this page and we will re-check within the day.
- **"Already redeemed"**: one redemption per account. DEMO-WELCOME is tied to account creation, not to the plan you pick first.
- **Trial accounts**: some codes refuse to apply while a free trial is running — let the trial finish or cancel it before redeeming.

## Where do new PixelPad codes come from?

PixelPad releases codes in three predictable rhythms, which is why this page can promise monthly coverage:

1. **Seasonal sales** — Black Friday and the New Year window carry the deepest cuts. The current [Black Friday deals guide](/guides/black-friday-deals-guide/) tracks which of this season's codes are worth acting on.
2. **Newsletter drops** — DEMO-PAD20 arrived through the October newsletter. Newsletter codes usually run to the end of the quarter.
3. **Partner bundles** — template-marketplace partnerships occasionally ship a bundled code. These are the rarest and the shortest-lived.

The official newsletter is the first place new codes land — everything there gets tested and added on this page within a day of release.

## Why did my PixelPad code stop working?

Codes expire on a schedule the vendor sets (usually tied to a campaign end date), and some are one-per-account. Expiry is enforced server-side: once the date passes, the billing endpoint rejects the code even if the input box still accepts the paste.

Expired entries stay on this page on purpose. DEMO-SUMMER25's row is how you can tell at a glance that this list is actually pruned rather than farmed from an old post — and expired seasonal codes are worth exactly one retry, because Black Friday codes in particular have historically returned in some form during the New Year sale.
