## Step-by-Step: Redeeming Codes In-Game

The beta client follows the same menu layout that Genshin Impact, Infinity Nikki, and most major free-to-play titles have trained us to expect. From the title screen:

1. **Log in and enter the game world.** The redemption option is not available from the login screen itself — you need to be in-game on your account.
2. **Open the main menu** (Options/Menu button on controller, or the hamburger icon on PC and mobile).
3. **Select Settings**, usually marked with a gear icon in the corner of the menu.
4. **Switch to the Account tab.** This is where account-bound utilities live — linked services, purchase history, and redemption.
5. **Choose Redeem Code** (labeled "Redemption Code" in some beta builds).
6. **Enter the code exactly as published.** Codes are case-sensitive in the beta client, and the text field does not auto-capitalize — the most common cause of failed redemptions.
7. **Confirm and check your mailbox.** Redeemed items go to the in-game mail, not directly into your inventory. Mail typically expires after 30 days, so claim early.

On console, typing with a gamepad is painful. If Aniimo ships a web redemption portal at launch (common for cross-platform F2P games, where you log into the official site, pick your server and character, and enter the code from a keyboard), we will link it here — it is genuinely the better route for PS5 and Xbox players.

## In-Game Mail vs Code Redemption

Aniimo uses two different delivery systems for free loot, and mixing them up causes half of all "where is my reward" confusion:

| | Redemption Codes | In-Game Mail |
|---|---|---|
| **How it works** | You enter a code string manually | Items appear in your mailbox automatically |
| **When it is used** | Social media giveaways, livestream drops, collab events | Pre-registration rewards, maintenance compensation, event payouts |
| **Action required** | Enter code, then claim from mail | Just claim from mail |
| **Expiration** | Code expires fast; mail lasts ~30 days after delivery | Mail typically expires after 30 days |
| **Typical source** | Twitter/X, Discord, livestreams | Developer distribution, milestone campaigns |

This distinction matters for pre-registration rewards specifically. The milestone loot you earn by pre-registering (Glimmer, Aniipod Ultras, the Sunlit Meadow outfit, and so on) will most likely arrive **by mail** after launch — no code to enter, as long as you pre-registered with the account you play on. Codes, by contrast, are for the promotional giveaways that start once the game is live. Neither exists yet as of August 15, 2026.

## Common Redemption Errors and Fixes

Every error screen below has a fix. Work down this table before assuming a code is dead:

| Error message | What it means | Fix |
|---------------|---------------|-----|
| "Invalid code" | Typo, wrong capitalization, or extra spaces | Re-enter carefully; codes are case-sensitive; paste instead of typing |
| "Code expired" | The code's redemption window closed | Follow official channels for fresh codes; redeem new ones immediately |
| "Already redeemed" | One redemption per account | Nothing to fix — check your mailbox for the unclaimed reward |
| "Region not available" | Code restricted to certain server regions | Confirm your account region matches the code's target region |
| "Redemption failed, try later" | Server congestion (common at launch) | Wait 10— 5 minutes and retry; avoid peak launch-day hours |

A launch-day tip from experience: when a popular code drops during a version livestream, millions of players redeem simultaneously and the server starts throwing generic failure errors even for valid codes. The code is fine — just be patient and retry.

No. Aniimo releases September 16, 2026, and no redemption codes exist before then. Any "working" pre-launch codes circulating online are fabricated. Pre-registration rewards are the only freebies available right now, and they are claimed by pre-registering, not by entering codes.

### Where is the redeem code option in Aniimo?

### Do I redeem codes on the website or in the game?

Both should work in principle. The beta client has an in-game redemption menu, and cross-platform F2P games typically add a web portal for console players. If Aniimo launches a web redemption page, use whichever is faster — the result is identical.

### Why does my code say "expired" when it was just posted?

Either the redemption window closed (codes for popular games can die within hours), or you found an old post being recirculated. High-traffic codes also occasionally fail with an expired error due to server congestion — retry after 10-15 minutes before giving up.

### Are redemption codes case-sensitive in Aniimo?

Yes, in the beta client. The input field does not auto-correct capitalization, so the safest approach is copying the code directly from the source and pasting it into the field, avoiding trailing spaces.
