## How do I redeem a CloudNote coupon code?

The redemption flow takes under a minute:

1. Sign in and open **Account → Subscription**.
2. Click **Redeem code**, paste one of the active codes above, and press **Confirm**. Codes are case-sensitive — copy-paste rather than type.
3. The invoice preview updates with the discount before payment. If the total did not move, check the rejection reason on screen (see below).
4. Discounts on active subscriptions start from the next billing period; new subscriptions get the discount immediately.

**If a code from the active list is rejected:**

- **"This code has expired"**: it most likely lapsed after our last re-test. Tell us in the comments and we will re-check within the day.
- **"Code already used"**: one redemption per account. DEMO-STUDENT additionally requires the education verification flow before it will apply.
- **"Not valid for this plan"**: DEMO-CYBER40 is yearly-only and DEMO-BUS15 is Business-only — match the code to the plan row in the table below.

## Why did my CloudNote code stop working?

Codes expire on vendor-set schedules, and CloudNote enforces expiry server-side: a lapsed code is rejected at redemption even though the input box still looks ready. One subtlety worth knowing — a discount redeemed on an active subscription applies from the next billing period, so redeeming on the last day of a code's life still works, it just starts later than you might expect.

Expired rows stay listed as history. DEMO-SPRING's entry is the proof this page actually prunes; and if a seasonal code you missed has a "returns each sale" pattern, one retry during the next campaign window is worthwhile.
