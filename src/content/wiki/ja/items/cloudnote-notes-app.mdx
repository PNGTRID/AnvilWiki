CloudNote は、このサイトの実用例のノートアプリ側です。架空のノートファースト SaaS を、完全な**ツールカード**として書き起こしたものです。「X とは何か・いくらか・クーポンはあるか」の検索に答えるエンティティページの形式です。製品の概要、2026年のプラン、有効なクーポン、向き不向きを一枚にまとめます。以下の記述はすべて架空のデモブランドについてのものです。再利用するのはページ構造のほうです。

## CloudNote とは?

CloudNote は構造化ノートアプリです。ノートブックとタグ、ノート同士の双方向リンク、Web クリップ、そして実際に見つかる全文検索を備えています。設計思想は「ノートはアプリより長生きする」で、書き出しはオープン形式、履歴はバージョン管理です。実務で効いてくるのは4つの面です:

1. **ノートとリンク** — Markdown 親和の編集とバックリンク。調査メモが積み上がるのではなく、つながっていきます。
2. **同期** — 端末間で即時。Basic は2台までで、これが有料に移行する最大の理由です。
3. **クリップ** — 記事をソース URL ごとノートブックに保存するブラウザ拡張。
4. **共有ワークスペース** — Business のチームノートブック。ロールと管理者向けの書き出し付きです。

## CloudNote の料金プラン(2026年)

| プラン | 料金 | 内容 |
| --- | --- | --- |
| Basic | $0 | ノート無制限、2台まで同期、60日間の履歴 |
| Plus | $6/月 または $60/年 | 端末無制限、全履歴、クリップ、統合 |
| Business | $12/席/月 | Plus の全内容+共有ワークスペースと管理者機能 |

このサイトのどこでもそうですが、年額サイクルが組み込みの第一割引レイヤーで、クーポンが第二レイヤーです。現行リストは[CloudNote クーポンコード](/ja/codes/cloudnote-codes/)ページにあり、今季は「年額40%オフ」の季節コードと「サイクル不問30%オフ」のコードが有効です。レイヤーの組み合わせ規則(何が重なり、どの順で適用するか)は[SaaS 割引スタッキングガイド](/ja/guides/saas-discount-stacking-guide/)にあります。

## CloudNote が向く人・向かない人

**向いているのは:** メモが調べ直す参考資料——調査、議事録、個人 Wiki——である人。バージョン履歴とオープンな書き出しがあるので、長期の保存先として安全です。

**別を探すべきとき:** 書くより描いて見せる仕事が中心なら、当サイトのもう一つのツールがその職務に合います([PixelPad デザインツール](/ja/items/pixelpad-design-tool/)のカードと、専用の[クーポンページ](/ja/codes/pixelpad-codes/))。また、メモがドキュメントの中で完結するなら、スタンドアロンのノートアプリよりライティングスイートの契約が勝つこともあります。

## このページ末尾の提案スロットについて

この形式のページは、末尾に任意の**アフィリエイト提案カード**を置けます。ツール実体ページの収益化スロットです。このテンプレートでは設定ファイルによるゲーティングで、初期状態は空です。サイト運営者が設定を追加するまで何も表示されません。このページ形式を再利用する人のための配線はこうなります:

```ts
// src/config/affiliates.ts — 配列が空の間はスロットは何も表示しない
export const affiliates = {
  suggestions: [
    {
      url: 'https://www.cloudnote.example/',
      title: 'CloudNote Plus を試す',
      description: 'このページで扱ったノートアプリ。',
      categories: ['items'],
    },
  ],
};
```

スロットが自動で処理するのは3つです。リンクに `rel="sponsored nofollow noopener"` が付くこと、ローカライズされたスポンサー開示ラベルが付くこと、1ページのカードは最大2枚に制限されること。アフィリエイトリンクを記事本文にハードコードしないでください。差し替え場所は config ファイル一箇所だけで、空のままなら表示なし(広告・コメントと同じ開箱契約)が保たれます。
