Emberfang（アッシュ・ワーデン）は、Anvil Questでほとんどのプレイヤーが最初に遭遇する大型ボスで、チュートリアル編の終わりにある Frostspire Approach の出口を守っています。このガイドでは、すべての攻撃パターンとダメージ数値、安全な攻撃チャンス、この戦闘を簡単にする装備構成、そして10回中9回の全滅を引き起こすミスを解説します。Emberfang に楽に勝てるなら中盤へ進む準備はできており、勝てないなら修正ポイントを正確に教えてくれる診断書です。

<Callout type="tip" title="クイックヒント">氷属性の武器はこの戦闘を約3分の1に短縮します。Frostpike は闘技場のゲートの2つ前のクエストで作成可能です。正確なレシピは[鍛造ガイド](/ja/guides/forging-guide/)を参照してください。</Callout>

## 挑戦前の準備

30秒の準備で試行ごとのランダム性のほとんどを消せます:

| 準備 | 理由 |
| --- | --- |
| レベル8以上（9だと余裕） | Emberfang のボルトは1発180ダメージ。レベル7のHPでは余裕がない |
| 氷属性武器（Frostpike が理想） | 火弱点ボス — 氷は2倍、火は4分の1のダメージ |
| 回復ポーション 3〜5個 | 1本で1ミスをカバー。5本なら練習試合も対応 |
| 上級凍結ポーション 1本 | フェーズ3の灼熱を完全にキャンセル（下記参照） |
| 先に雑魚を排除 | Ash Hound 2体は死んだまま放置すると再出現する |

ポーションは Mara の店で1本25〜60ゴールド。足りなければ[コードページ](/ja/codes/all-codes/)の最新コードを交換しましょう — FORGE-2026 だけで買い物リストの全額をカバーできます。

## ボス概要

| ステータス | 値                                    |
| ---------- | ------------------------------------- |
| 推奨レベル | 8以上                                 |
| HP         | 4,200                                 |
| 弱点       | 氷                                    |
| 耐性       | 火                                    |
| 場所       | Ashen Keep、Shattered Isles 第1幕     |

Emberfangはゲートキーパー的なボスです。良いニュース:彼には厳密で学習可能なパターンがあります — 3フェーズ、各フェーズにちょうど1つのメカニクス、各メカニクスにちょうど1つの正解。最初の斉射がどちら側から来るか以外、この戦闘にランダム性はありません。

## フェーズ1：ファイアボルト斉射（HP 100%〜66%）

Emberfangは戦闘開始と同時に、3秒ごとに拡散状に3発の火の矢を発射します。矢は中速で飛び、直撃で180ダメージ。耐えられますが、3連続ヒットでレベル8の試技は終わります。

**対策**: 右にストレイフしましょう。3発すべて左から右に扇状に広がるため、右方向への一定移動だけでダッシュを使わずに斉射を完全に回避できます。

リズムは:溜めの間に右へ3歩、斉射の合間に自分も1〜2発、の繰り返し。レベル8のフェーズ1は Frostpike ありで約90秒、なしで150秒です。

## フェーズ2: 燃え盛る大地（HP 66%〜33%）

HPが66%になると、Emberfangは地面を叩き、広がる炎の輪を生成します。ヒットすると2秒間灼熱状態になり、燃えている間に直後のボルト斉射が来るため、ほぼ致命傷になります。

<Accordion title="フェーズ2の詳細（ここで死に続けるなら開いてください）">
  <p><strong>輪のタイミング</strong>:輪は1.2秒ごとに3枚1組で広がります。各輪が足元に届いた瞬間にジャンプ — 猶予は輪ごとに0.4秒です。</p>
  <p><strong>ダッシュが失敗する理由</strong>:ダッシュのクールダウンは6秒ですが、最後の輪の2秒後に追撃斉射が来ます。輪はジャンプで越え、ダッシュは斉射用に温存。</p>
  <p><strong>安全地点</strong>:闘技場の角にある2つの石の火鉢からは輪が発生しません。火鉢の後ろに立てば、3枚の輪のうち2枚しかジャンプしなくて済みます。</p>
</Accordion>

**対策**: 各輪をジャンプで越えましょう。タイミングは余裕があり（輪ごとに0.4秒の猶予）。ダッシュは輪ではなく、追撃の斉射のために温存してください。

## フェーズ3: インフェルノ激化（HP 33%〜0%）

HPが33%を下回ると、Emberfangは激化状態に入ります。移動速度+30%、ボルト斉射が3発から5発に、燃え盛る大地の輪が2倍の頻度で発生します。5発の扇状拡散も左から右に広がりますが、隙間は「気軽な歩き」から「意図的なストレイフ」に変わります。

**対策**: フェーズ3開始時に氷属性ポーションを使いましょう。氷バフは灼熱効果を完全にキャンセルし、この戦闘で最も危険なメカニクスを無力化します。残るのは5発ボルトのストレイフと速い輪だけ — どちらも2フェーズかけて練習済みです。

## 推奨装備

デフォルトの構成は[初心者ガイド](/ja/guides/beginner-guide/)のルートを前提にしています:

| スロット   | アイテム               | 理由                                        |
| ---------- | ---------------------- | ------------------------------------------- |
| 武器       | Frostpike（氷）        | 火弱点ボスに2倍ダメージ                     |
| 防具       | Emberweaveセット       | 火耐性+40                                   |
| アイテム   | 上級凍結ポーション     | フェーズ3の灼熱をキャンセル                 |
| アクセサリ | クリティカルチャーム   | ボルト溜め中の頭部は2倍クリティカルゾーン   |

**別案 — メイジ（レベル8）**: Firebolt は火属性でここでは4分の1に減ります。代わりに**アイスシャード**スキルを取りましょう（Frostspire Approach のトレーナーから無料）。HPの低いクラスはストレイフより円を描くケイティングが有効で、輪のジャンプゼロのソロダンスになります。

**別案 — ローグ（レベル8）**: 溜めにバックスタブ。すべての斉射には0.8秒の溜めがあり、その間クリティカルゾーンが露出します。その窓でのバックスタブクリットはHPバーの15%。リスクは高いが、約2分速い。

## よくあるミス

- **ボルトに向かって回避する。** 初心者はパニックで前方にダッシュし、3発すべて受けます。フェーズ1ではダッシュせずストレイフしましょう。
- **炎の輪にダッシュを使う。** ダッシュはクールダウン6秒です。追撃のボルトのために必要です。輪はジャンプで越えましょう。
- **凍結ポーションを忘れる。** 氷バフなしのフェーズ3はコイントスです。あれば実質的に戦闘終了です。
- **「時間の節約」にレベル6〜7で挑む。** これは最も遠い道です:180ダメージのボルトは灼熱1回分でレベル7のHPを一撃で消します。イノシシ2群を倒してレベル8に上げる方が、5回の失敗より速いです。
- **Molten Gem を売る。** ドロップ率35%で、Emberweave 胸装備に4つ必要です — 完全な買い物リストは[鍛造素材ガイド](/ja/items/forging-materials-guide/)を参照してください。

## よくある質問

<Accordion title="レベル不足でも倒せますか？">
  Frostpike とポーション5本があればレベル6でも可能ですが、理由がありません:Oakwood Vale のサブクエストは15分で400コインとレベル8分のXPをくれます。レベル不足の挑戦は、より悪い報酬で戦闘を学ぶだけです。
</Accordion>

<Accordion title="Emberfang は周回討伐できますか？">
  はい — 死亡から20分で再出現し、Molten Gem（35%）は序盤の主な周回対象です。平均3討伐で1個、固定報酬込みで時給約2,550コインです。
</Accordion>

<Accordion title="火属性武器がほとんどダメージを与えられないのは？">
  彼は火耐性があります:火は25%、無属性は100%、氷は200%のダメージ。闘技場の直前に火のアンスタブがありますが、これは初心者を火属性強化に誘う罠です — 無視しましょう。
</Accordion>

## まとめ

フェーズ1は右にストレイフ。フェーズ2は輪をジャンプ。フェーズ3開始時に凍結ポーション。[Frostpikeの評価](/ja/guides/weapon-tier-list/)を持参。これで勝てます。

初めてのボス戦なら[初心者ガイド](/ja/guides/beginner-guide/)にポーションのタイミングまとめがあります。凍結ポーションの費用は[コードページ](/ja/codes/all-codes/)の無料ゴールドで賄えます。Emberfang が物足りなくなったら、第2幕の [Stormcaller](/ja/bosses/stormcaller/) が次の — はるかに厳しい — 試験です。
