Gelum（フロスト・ワーデン）は、Anvil Questでほとんどのプレイヤーが最初に遭遇する大型ボスです。このガイドでは、すべての攻撃パターン、安全な攻撃チャンス、そしてこの戦闘を簡単にする装備構成を解説します。

## ボス概要

| ステータス | 値                                     |
| ---------- | -------------------------------------- |
| 推奨レベル | 8以上                                  |
| HP         | 4,200                                  |
| 弱点       | 火                                     |
| 耐性       | 氷                                     |
| 場所       | Frostspire Keep、Shattered Isles 第1幕 |

Gelumはゲートキーパー的なボスです。楽に倒せないなら、まだ中盤に進む準備ができていません。良いニュースは、彼には厳密で学習可能なパターンがあることです。

## フェーズ1：アイスシャード斉射（HP 100%〜66%）

Gelumは戦闘開始と同時に、拡散状に3発の氷の刃を発射します。刃は中速で飛び、直撃で180ダメージを与えます。

**対策**: 右にストレイフしましょう。3発すべて左から右に扇状に広がるため、右方向への一定移動だけで斉射を完全に回避できます。

## フェーズ2: 凍てつく大地（HP 66%〜33%）

HPが66%になると、Gelumは地面を叩き、広がる氷の輪を生成します。ヒットすると2秒間凍結され、直後のシャード斉射で致命傷になります。

**対策**: 各輪をジャンプで越えましょう。タイミングは余裕があり（輪ごとに0.4秒の猶予）。ダッシュは輪ではなく、追撃の斉射のために温存してください。

## フェーズ3: ブリザード激化（HP 33%〜0%）

HPが33%を下回ると、Gelumは激化状態に入ります。移動速度+30%、シャード斉射が3発から5発に、凍てつく大地の輪が2倍の頻度で発生します。

**対策**: フェーズ3開始時に火属性ポーションを使いましょう。火バフは凍結効果を完全にキャンセルし、この戦闘で最も危険なメカニクスを無力化します。

## 推奨装備

| スロット   | アイテム             | 理由                                        |
| ---------- | -------------------- | ------------------------------------------- |
| 武器       | Emberclaw（火）      | 氷弱点ボスに2倍ダメージ                     |
| 防具       | Frostpikeセット      | 氷耐性+40                                   |
| アイテム   | 上級火炎ポーション   | フェーズ3の凍結をキャンセル                 |
| アクセサリ | クリティカルチャーム | シャード溜め中の頭部は2倍クリティカルゾーン |

## よくあるミス

- **シャードに向かって回避する。** 初心者はパニックで前方にダッシュし、3発すべて受けます。フェーズ1ではダッシュせずストレイフしましょう。
- **凍てつく輪にダッシュを使う。** ダッシュはクールダウン6秒です。追撃のシャードのために必要です。輪はジャンプで越えましょう。
- **火炎ポーションを忘れる。** 火バフなしのフェーズ3はコイントスです。あれば実質的に戦闘終了です。

## まとめ
